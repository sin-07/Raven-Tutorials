# Design System Specification

## Color Palette
- **Obsidian Dark**: `#05070a` (Global canvas)
- **Glass Panel**: `#0d1117/80` (Backdrop blur)
- **Emerald Pulse**: `#10b981` (Primary brand aura)
- **Electric Orange**: `#f97316` (Active badge & highlight marker)
- **Titanium Zinc**: `#71717a` (Secondary typography)

## Typography
- **Headings**: Cinzel & Space Grotesk
- **Data/Metrics**: Monospace (JetBrains Mono / Inter)
- **Body**: Inter with clean 1.6 line height rhythm
