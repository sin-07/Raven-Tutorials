# Raven Tutorials - System Architecture

## Technical Stack
- **Framework**: Next.js 14 App Router
- **Database**: MongoDB via Mongoose
- **Styling**: TailwindCSS with cyber dark glassmorphic theme
- **Media**: Cloudinary integration for PVC identity photos
- **Authentication**: JWT with secure HTTP-only cookies

## Core Modules
1. **Student Portal**: CR80 PVC identity pass generation with dynamic high-resolution QR codes.
2. **Attendance Tracking**: Real-time percentage computation with 75% examination eligibility barrier.
3. **Tuition Fee Reconciliation**: Three-tier installment ledger with receipt downloads.
4. **Live Classes**: Scheduled lecture links with role-gated teacher/student rooms.
