# Architecture Overview

## System Architecture
Raven Tutorials is engineered with Next.js 14 App Router, TypeScript, React 18, and MongoDB Atlas.

### Tech Stack
- **Framework**: Next.js 14 App Router
- **Database**: MongoDB Atlas via Mongoose
- **Styling**: Tailwind CSS + Cyber Emerald obsidian theme
- **Animations**: GSAP 3 & Framer Motion
- **Auth**: JWT HttpOnly session cookies
