# API Reference

## REST API Endpoints

### Public Endpoints
- `GET /api/courses`: Retrieve list of published courses
- `GET /api/articles`: Retrieve published academic articles
- `POST /api/contact`: Submit student/parent contact enquiry
- `POST /api/admission`: Register student for admission

### Authentication
- `POST /api/auth/login`: Student login
- `POST /api/auth/logout`: Student logout
- `GET /api/auth/verify`: Session token verification
